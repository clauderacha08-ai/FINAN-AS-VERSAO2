Antes de começar, conecte o app ao seu Firebase (gratuito)

Por quê? Seus dados financeiros ficam salvos com segurança na sua própria conta Google/Firebase — ninguém além de você tem acesso, e dá pra usar em vários aparelhos.
📋 Passo a passo (5 minutos)
  1. Acesse console.firebase.google.com e crie um projeto (pode ser "financas-vida")
  2. No menu lateral: Compilação → Authentication → aba "Sign-in method" → ative E-mail/senha
  3. Compilação → Firestore Database → Criar banco de dados → modo produção
  4. Em Firestore, aba Regras, cole o texto abaixo e clique em Publicar
  5. Volte em ⚙️ Configurações do projeto → Geral → role até "Seus apps" → clique no ícone </> (Web) → registre um app
  6. Copie o bloco const firebaseConfig = {'{'}...{'}'} que aparecer e cole no campo abaixo
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId} { allow read, write: if request.auth != null && request.auth.uid == userId; } match /allowed_emails/{emailKey} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.token.email == 'chicho.vini7@hotmail.com'; } } }
Só quem estiver na lista de e-mails liberados (gerenciada pelo administrador dentro do app, em Configurações) consegue criar conta e entrar — mesmo com o link do app em mãos, ninguém mais consegue usar.
Depois de publicar o app (ex: no Netlify), volte em Authentication → Settings → Authorized domains e adicione o domínio do site — senão o login trava com erro "unauthorized-domain".
